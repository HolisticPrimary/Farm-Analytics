§ 05 อุณหภูมิ & แรงลม ตามอายุ

เกณฑ์ของฟาร์ม (ไฟล์เกณฑ์.xlsx) — อุณหภูมิเป้า + ความเร็วลมรายวัน + สัญญาณเตือนตามช่วงอายุ

5A · เกณฑ์อุณหภูมิ & ความเร็วลม รายวัน (เกณฑ์ฟาร์ม)

อุณหภูมิเป้าหมายลดลง ~0.3°C/วัน · ความเร็วลมเพิ่มตามอายุ · ปั๊มแพดเปิดเมื่ออุณหภูมิถึงค่าที่กำหนด
วันที่อุณหภูมิเป้า (°C)ความเร็วลม (FPM) ≈ m/sปั๊มแพดเปิดที่ (°C)

§ 07 สุขภาพรายวัน & การเติบโต

ข้อมูลที่ดึงเพิ่มจากใบหน้าเล้า — น้ำ:อาหาร, แยกตายจริง/คัด, รูปแบบเช้า/เย็น, น้ำหนักจริงเทียบเกณฑ์คละเพศ, อาหารหก/สูญเปล่า

7A · อัตราส่วน น้ำ : อาหาร

มาตรฐาน 1.5–2.4 · ต่ำ = ไก่ดื่มน้ำน้อย (อาจป่วย) · สูง = heat stress / ท้องเสีย — สัญญาณเตือนเบอร์ 1
#ฟาร์ม/เล้าอายุ น้ำ (ล.)อาหาร (kg)น้ำ:อาหาร สถานะคำแนะนำ

7B · แยก "ตายจริง" vs "คัด" + รูปแบบ เช้า/เย็น

คัด = การจัดการเชิงรุก (ดี) · ตายจริง = สูญเสียคุมไม่ได้ (แย่) · ตายเย็นเยอะ = heat stress

7C · น้ำหนักจริง เทียบเกณฑ์ "คละเพศ"

เทียบน้ำหนักชั่งจริงกับ เกณฑ์ STD คละเพศของฟาร์ม (อายุ 1–50 วัน) — ต่ำกว่าเกณฑ์ = โตช้า ต้องเช็คอาหาร/สุขภาพ
#ฟาร์ม/เล้าอายุ น.น.จริง (kg) เกณฑ์คละเพศ (kg) ส่วนต่าง สถานะ

7D · อาหารหก/สูญเปล่า (ลงสะสม vs กินสะสม)

ช่องว่างระหว่าง %อาหารที่ลงเล้า กับ %อาหารที่ไก่กินจริง = อาหารที่ไม่ถึงปากไก่ (เงินรั่ว)
#ฟาร์ม/เล้า%อาหารลงสะสม %อาหารกินสะสมช่องว่างสถานะ

§ 10 ตั้งค่า · เชื่อม Google Sheets

เชื่อมต่อ Google Sheet เพื่อเก็บประวัติข้ามวัน · กราฟที่ publish จาก Sheets จะแสดงด้านล่างเพื่อตรวจสอบทันที

1️⃣ Web App URL (Apps Script) · รับข้อมูลที่อัปโหลด → append เข้า Sheet

2️⃣ URL กราฟจาก Google Sheets · ฝังมาแสดงด้านล่าง

วางได้ทั้ง URL ตรงๆ หรือโค้ด <iframe ...> เต็มๆ — ระบบจะดึง src ให้เอง

3️⃣ โค้ด Apps Script · paste ใน Sheet → Extensions → Apps Script

เปิด Google Sheet ใหม่ → Extensions → Apps Script → ลบของเดิม → paste โค้ดนี้ → Save → Deploy → Web app
กำลังโหลด...

📖 ขั้นตอนการตั้งค่า (ทำครั้งเดียว ~10 นาที)

  1. สร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น "ประวัติฟาร์ม"
  2. เปิด Apps Script: เมนู Extensions → Apps Script
  3. Paste โค้ด จากกล่องข้างบน → กด Save (💾)
  4. Deploy: Deploy → New deployment → Type: Web app
    Execute as: Me · Who has access: Anyone → Deploy → Authorize
  5. Copy Web app URL → วางในกล่อง 1️⃣ ข้างบน → กดบันทึก
  6. ทดสอบเชื่อมต่อ ด้วยปุ่ม 🔬 (ควรเห็น "Sync ล่าสุดสำเร็จ")
  7. อัปโหลดใบหน้าเล้าทดสอบ → ดูใน Sheet ว่ามีแถวเพิ่ม
  8. ทำกราฟใน Sheet (Insert → Chart) ตามใจ
  9. Publish กราฟ: คลิกกราฟ → ⋮ → Publish chart → Copy URL
  10. วาง URL กราฟ ในกล่อง 2️⃣ → กดบันทึก → กราฟปรากฏด้านล่างทันที

🔒 ความปลอดภัย & ข้อจำกัด

URL ลับ: Web app URL ของ Apps Script ยาวและสุ่ม คนภายนอกเดาไม่ได้ ปลอดภัยพอสำหรับฟาร์มทั่วไป
เพิ่มความปลอดภัย: ในโค้ด Apps Script ใส่ค่า SECRET (ตอนนี้ FarmSense ยังไม่ส่ง secret — ใส่ '' ไว้ก่อน)
ข้อมูลที่ส่ง: KPI สำคัญต่อเล้า (เล้า, อายุ, ตาย, อาหาร, น้ำ, น้ำหนัก) ไม่ส่งไฟล์ Excel ดิบ
localStorage: URL เก็บใน browser นี้เท่านั้น — ใช้คนละเครื่องต้องตั้งค่าใหม่

§ 06 Export ข้อมูล

ดาวน์โหลดผลวิเคราะห์ในหลายรูปแบบ — ใช้พิมพ์, ส่งเมล, หรือนำเข้า BI tool

เลือกรูปแบบ

คู่มือใช้งาน

  1. เปิดเบราว์เซอร์ (Chrome, Edge, Safari, Firefox ใช้ได้หมด)
  2. ลากไฟล์ใบหน้าเล้า .xlsx มาวางในกล่อง upload — ทำได้ทีละหลายไฟล์
  3. ระบบจะตรวจชีท "ประมาณการไก่คงเหลือจับ" โดยอัตโนมัติและ parse ข้อมูล
  4. คลิกแท็บ ตามที่ต้องการดู — ทุกอย่างคำนวณใน browser ของอาร์มเอง ไม่มีการส่งข้อมูลไป server
  5. ปรับค่าราคา ในแท็บ FCR & กำไร → matrix จะ recompute ทันที
  6. Export → คลิก "พิมพ์/Save as PDF" หรือดาวน์โหลด CSV/JSON

No tracking — ไม่มี analytics, cookies, หรือ external requests (ยกเว้น fonts.googleapis สำหรับฟอนต์)
