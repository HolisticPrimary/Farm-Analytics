1รู้จัก FarmSense — มันช่วยอะไร

FarmSense คือเครื่องมือวิเคราะห์ฟาร์มไก่เนื้อแบบครบวงจร เปิดในเบราว์เซอร์ (Chrome / Safari / Firefox / Edge) แล้วอัปโหลดไฟล์ "ใบหน้าเล้า" Excel ที่ใช้กันในฟาร์ม — ระบบจะคำนวณและสรุปข้อมูลให้ทันที โดยทำงาน 100% บนเครื่องของคุณ ข้อมูลไม่ออกจากเครื่องไปไหน

หัวใจ

FarmSense ไม่ได้สร้างตัวเลขใหม่ — มันเอาข้อมูลที่ฟาร์มกรอกในใบหน้าเล้าอยู่แล้ว มาคำนวณ-เปรียบเทียบ-จัดอันดับ ให้เห็นภาพรวมในแว็บเดียว แทนที่จะต้องเปิดดูทีละเล้า

ระบบช่วยตอบคำถามอะไรบ้าง

คำถามที่ฟาร์มเจอบ่อยFarmSense ตอบยังไง
วันนี้ เล้าไหนต้องเข้าไปดูก่อน?"เล้าที่ต้องดูวันนี้" — จัดอันดับเล้าตามคะแนนเสี่ยงรวม
ไก่กินอาหารน้อยลงเพราะอะไร?เทียบกินจริงกับเกณฑ์ฟาร์ม + เช็คอัตราน้ำ:อาหาร
ตายเยอะตอนเย็น — heat stress?แยกตายเช้า/เย็น + จับรูปแบบให้อัตโนมัติ
รุ่นนี้กำไรเท่าไหร่?คำนวณ break-even FCR + กำไรต่อตัว + กำไรรวม
รุ่นนี้ดีขึ้นกว่ารุ่นก่อนไหม?เก็บประวัติ + เทียบ %ตาย / ความเร็วการตายข้ามรอบ

หน้าจอหลัก — 8 แท็บ

  1. ภาพรวม — สรุปทั้งหมด + "เล้าที่ต้องดูวันนี้"
  2. ตาย & วิธีแก้ — วินิจฉัยทีละเล้า + แนะนำการแก้ไข
  3. อาหาร vs เกณฑ์ฟาร์ม — เทียบการกินจริงกับเกณฑ์
  4. FCR & กำไร — คำนวณกำไร + sensitivity matrix
  5. อุณหภูมิ & ลม — เกณฑ์รายวัน + wind chill
  6. สุขภาพ & เติบโต — น้ำ:อาหาร, ตาย/คัด, น้ำหนัก, อาหารหก
  7. ประวัติ & แนวโน้ม — เก็บ snapshot เทียบรอบต่อรอบ
  8. Export — ดาวน์โหลด JSON / CSV / พิมพ์ PDF

2เริ่มต้น — อัปโหลดและเปิดดูข้อมูล

1. เปิดเว็บไซต์

เปิดเบราว์เซอร์ใดก็ได้ ไปที่:

https://holisticprimary.github.io/Farm-Analytics/

หรือดับเบิลคลิกไฟล์ farmsense.html ที่เก็บไว้ในเครื่อง — ใช้งานได้แม้ไม่มีอินเทอร์เน็ต

2. อัปโหลดไฟล์ใบหน้าเล้า

ลากไฟล์ Excel (.xlsx / .xls) มาวางในกล่องด้านบน หรือ คลิกเพื่อเลือกไฟล์ — ใช้ได้พร้อมกันหลายฟาร์ม

ข้อกำหนด

ไฟล์ต้องมีชีทชื่อ "ประมาณการไก่คงเหลือจับ" (หรือคำที่ใกล้เคียง) ระบบจะหาเอง หลังอัปโหลด — ถ้าระบบบอกว่าหาคอลัมน์บางตัวไม่เจอ ใช้ปุ่ม "⚙ ปรับการ map คอลัมน์" เลือกเองว่าคอลัมน์ไหนคืออะไร ระบบจะจดจำ template นั้นไว้ — ครั้งหน้าไม่ต้องปรับซ้ำ

3. คลิกแท็บที่ต้องการดู

แท็บอยู่ด้านบนของหน้าจอ คลิกเพื่อสลับมุมมอง การคำนวณทุกอย่างเสร็จในเสี้ยววินาที

ความปลอดภัย

ไม่มีการส่งข้อมูลออกที่ไหน ทุกการคำนวณเกิดบนเบราว์เซอร์ของคุณเท่านั้น ไม่มี server, ไม่มี analytics, ไม่ต้องล็อกอิน — ปิดเบราว์เซอร์ปุ๊ป ข้อมูลก็หายปั๊ป (ยกเว้นถ้าใช้ฟีเจอร์ "ประวัติ" จะเก็บไว้ในเบราว์เซอร์เครื่องคุณเอง)

3ภาพรวม & "เล้าที่ต้องดูวันนี้"

แท็บภาพรวม · §01

นี่คือ หน้าแรกที่ต้องดูทุกเช้า — มี 3 ส่วน: KPI รวม, เล้าที่ต้องดูวันนี้, เปรียบเทียบฟาร์ม + Heatmap

KPI รวม (การ์ดด้านบน)

การ์ดหมายความว่า
ไก่คงเหลือรวมไก่ที่ยังมีชีวิตทั้งหมด ทุกฟาร์มทุกเล้ารวมกัน
ตายสะสมรวมตายไปแล้วทั้งหมด พร้อม %ตายเฉลี่ย (เกณฑ์ดี < 2%)
ตายวันนี้ตายในรอบวันล่าสุด + อัตราต่อวัน (เกณฑ์ดี < 0.06%)
เล้าวิกฤตนับเล้าที่ %ตายสะสม ≥ 4% (ต้องแก้ด่วน)

"เล้าที่ต้องดูวันนี้" — หัวใจของระบบ

นี่คือสิ่งที่ FarmSense ทำได้แตกต่างจากการเปิดดูตารางทีละเล้า — ระบบจะ คำนวณคะแนนความเสี่ยงรวมของแต่ละเล้าโดยเอาทุกสัญญาณมารวมกัน (%ตาย + อาหาร + น้ำ:อาหาร + รูปแบบตาย + น้ำหนัก + density + เทียบเล้าพี่น้อง + วัคซีน) แล้วจัดอันดับให้เลย — "คะแนนสูง = ต้องดูก่อน"

Heatmap ทุกเล้า

ด้านล่างของแท็บภาพรวม จะมี Heatmap แสดง %ตายสะสมของทุกเล้าทุกฟาร์ม เลือกสีตามความรุนแรง — ไล่จากเขียว (ดี) → เหลือง → ส้ม → แดง (วิกฤต) ใช้สแกนรวดเดียวหาเล้าที่สีแดงแสบตา

การอ่านแต่ละช่อง

แต่ละช่องของ Heatmap แสดงข้อมูลสำคัญ 3 อย่าง:

ตัวอย่างจริง · ฟาร์มพีพฟู้ดชัยนาท เล้า 1

บนหน้าจอจะเห็นช่องนี้ (พื้นสีเหลือง-เขียวอ่อน):

เล้า 1
2.49%
1,002 / 40.3k
เล้า 1 → หมายเลขเล้า
2.49% → %ตายสะสม
1,002 / 40.3k → ตาย 1,002 ตัว จากที่ลง 40,300 ตัว
สีเหลือง-เขียวอ่อน → กลุ่ม 1.5–2.5% (เริ่มสูงเล็กน้อย)

ที่มาของ 2.49%:

%ตายสะสม = 1,002 ÷ 40,290 × 100 = 2.487% ≈ 2.49% (ปัดทศนิยม)
วิธีใช้ Heatmap ในชีวิตประจำวัน
  1. เปิดแท็บ "ภาพรวม" → เลื่อนลงมาด้านล่างสุด
  2. สแกนหาช่องสีแดงก่อน — เล้าวิกฤต (%ตาย ≥ 4%) ต้องลงพื้นที่เดี๋ยวนี้
  3. เลื่อนเมาส์บนช่อง → tooltip โชว์รายละเอียด (ที่มาลูกไก่, density, ตายสะสม)
  4. คลิกแท็บ "ตาย & วิธีแก้" หาเล้านั้นเพื่อดูสาเหตุ + วิธีแก้

4%ตายสะสม — ตัวเลขที่สำคัญที่สุด

%ตายสะสม = เปอร์เซ็นต์ของไก่ที่ตายไปแล้วจากทั้งหมดที่ลง

เป็นตัวชี้วัด สำคัญที่สุดในการประเมินสุขภาพรอบนี้ — ฟาร์มดีต้องคุมให้ < 2% ตลอดรอบ 35–42 วัน

คำนวณยังไง

%ตายสะสม = ตายสะสม ÷ ยอดไก่ลง × 100
ตัวอย่างจริง · ฟาร์มพีพีฟู้ดชัยนาท เล้า 1

• ยอดไก่ลง = 40,290 ตัว
• ตายสะสม = 1,002 ตัว
• %ตายสะสม = 1,002 ÷ 40,290 × 100 = 2.49%

หมายเหตุ: FarmSense อ่านค่านี้ตรงจากคอลัมน์ "%ตายสะสม" ในไฟล์ Excel ที่ฟาร์มกรอก — ไม่ได้คำนวณซ้ำ แต่มีการตรวจสอบความสอดคล้องโดยเทียบกับสูตรข้างบน

เกณฑ์ตัดสิน — ทำไมต้อง 2%

%ตายสะสมสีสถานะการตีความ
< 1.5%ดีมากดีฟาร์มจัดการได้ดี (top tier)
1.5–2.5%เริ่มสูงเริ่มสูงเล็กน้อยปกติของช่วงปลายรอบ จับตาดู
2.5–3.3%เฝ้าระวังเฝ้าระวังหาสาเหตุ — สาย? supplier? heat stress?
3.3–4%สูงสูงแก้ไขด่วน เพิ่มความถี่ตรวจ
≥ 4%วิกฤตวิกฤตโทร vet, necropsy, ตรวจซัพพลายเออร์
มาตรฐาน

มาตรฐานสายพันธุ์ Ross 308 (ที่ฟาร์มไทยส่วนใหญ่เลี้ยง) คือ ~3.5% ตลอดรอบ 35 วัน ฟาร์มที่บริหารดีจะอยู่ 1.5–2.5% ในช่วงปลายรอบ (เกินจากนี้ก็จะเริ่มน่าห่วง)

หา %ตายสะสมได้ที่ไหนในเว็บ

  • แท็บภาพรวม — KPI การ์ดที่ 2 "ตายสะสมรวม" (ค่าเฉลี่ยของทุกฟาร์ม)
  • แท็บภาพรวม → การ์ดฟาร์ม — %ตายสะสมของแต่ละฟาร์ม
  • แท็บภาพรวม → Heatmap — แต่ละเล้ามี %ตายของตัวเองพร้อมสี
  • แท็บ "ตาย & วิธีแก้" — ตารางครบทุกเล้า เรียงตาม %ตาย

5"ตายจริง" vs "คัด" — ทำไมต้องแยก

ไฟล์ใบหน้าเล้าแยกข้อมูลเป็น 4 ช่อง — ไก่ตายเช้า / ไก่คัดเช้า / ไก่ตายเย็น / ไก่คัดเย็น ส่วนใหญ่ฟาร์มดูแต่ "รวม" — FarmSense แยกให้เห็นชัด เพราะความหมายต่างกันมาก

✓ ไก่คัด

การ จัดการเชิงรุก — สัตวบาลตัดสินใจคัดไก่ที่อ่อนแอ/พิการออก เพื่อรักษาภาพรวมของเล้า

คัดเยอะ = บริหารดี — แสดงว่าทีมตื่นตัว

✗ ไก่ตาย

ความสูญเสียที่ควบคุมไม่ได้ — ตายเองจากโรค ความร้อน อุบัติเหตุ ฯลฯ

ตายเยอะ = มีปัญหา — ต้องหาสาเหตุ

สูตร

ตายจริง = ไก่ตายเช้า + ไก่ตายเย็น คัด = ไก่คัดเช้า + ไก่คัดเย็น รวม = ตายจริง + คัด %คัด = คัด ÷ รวม × 100
ตัวอย่าง · ฟาร์ม 10 เล้า · เล้า 1
เช้าเย็นรวม
ตายจริง161329
คัด61016
รวม222345

%คัด = 16/45 = 36% — แสดงว่าทีมคัดอย่างจริงจัง (ดี)

ตรวจสอบ: 29 + 16 = 45 ตรงกับ "ตายต่อวัน" ในไฟล์ ✓ (ระบบเช็คทุกเล้า)

วิธีอ่าน

• %คัดสูง (40%+) + %ตายรวมต่ำ = ฟาร์มดี บริหารดี
• %คัดต่ำ (≤10%) + %ตายรวมสูง = ทีมไม่ได้คัด ปล่อยให้ตายเอง — ต้องสอน
• ทั้ง 2 ตัวสูงพร้อมกัน = วิกฤต — ทีมพยายามแล้วแต่ปัญหาใหญ่กว่า

6รูปแบบ เช้า/เย็น — บอกอะไร

การที่ไก่ตายกระจุกเวลาเดียวกัน มีความหมายเฉพาะ — FarmSense จับรูปแบบให้อัตโนมัติ

รูปแบบสังเกตได้จากสาเหตุที่น่าจะเป็น
เย็นหนัก (HEAT)ตายเย็น > เช้า × 1.5 เท่าHeat stress ช่วงบ่าย-เย็นอากาศร้อนสะสม ระบบระบายไม่พอ
เช้าหนัก (NIGHT)ตายเช้า > เย็น × 1.5 เท่าหนาว/ปัญหากลางคืน ระบบทำความอุ่นล้มเหลว หรือไฟตกกลางดึก
สม่ำเสมอ (EVEN)ใกล้เคียงกันตายแบบ random — ไม่มีสาเหตุเฉพาะเวลา
ตัวอย่างจริง

เล้า 1 (ตายเช้า 22, เย็น 23) → EVEN → ปกติ

เล้า 2 (ตายเช้า 34, เย็น 3) → NIGHT → หนาว/กลางคืนผิดปกติ ต้องตรวจฮีตเตอร์

เล้า 4 (ตายเช้า 23, เย็น 40 รวมคัด) → HEAT → ช่วงบ่ายร้อน ต้องเร่งพัดลม

เห็น HEAT — ทำยังไง

1. ดูอุณหภูมิเล้าตอนบ่าย เทียบกับเกณฑ์ที่อายุนั้น
2. เปิดแท็บ "อุณหภูมิ & ลม" ดูแรงลม FPM ที่ต้องใช้
3. เพิ่มจำนวนพัดลม / เปิดปั๊มแพดเร็วขึ้น
4. ถ้าอากาศเย็นแล้วยัง HEAT — เช็คแสงไฟ density การกระจายตัวของไก่

7อาหาร — ไก่กินตามเกณฑ์หรือไม่

แท็บ "อาหาร vs เกณฑ์ฟาร์ม" · §03

เทียบ กรัม/ตัว/วัน ที่ไก่กินจริง กับ เกณฑ์อาหารของฟาร์ม (จากไฟล์เกณฑ์ที่ฟาร์มกำหนดเอง) — ระบบยังโชว์เทียบกับมาตรฐาน Ross 308 เป็นตัวเทียบรองด้วย

คำนวณยังไง

กรัม/ตัว/วัน = อาหาร (kg) × 1000 ÷ ยอดไก่คงเหลือ ส่วนต่าง (%) = (กินจริง − เกณฑ์ฟาร์ม) ÷ เกณฑ์ฟาร์ม × 100
ตัวอย่าง · ฟาร์ม 10 เล้า · เล้า 1

• อาหารวันนี้ = 6,600 kg
• ไก่คงเหลือ = 35,392 ตัว
• กรัม/ตัว/วัน = 6,600 × 1,000 ÷ 35,392 = 186.5 ก./ตัว/วัน

• เกณฑ์ฟาร์มที่อายุ 36 วัน = 175 g
• ส่วนต่าง = (186.5 − 175) ÷ 175 × 100 = +6.6%

→ สถานะ: OVERFEED (เกินเกณฑ์ +5%) → ตรวจการสิ้นเปลือง

เกณฑ์สถานะ

ส่วนต่าง %สถานะหมายความว่าทำยังไง
> +5%OVERFEEDกินเกินเกณฑ์เช็คสิ้นเปลือง / recheck สูตร / อาหารหก
−5 ถึง +5%OKปกติ กินตามเกณฑ์ดำเนินการต่อ
−5 ถึง −10%LIGHTน้อยเล็กน้อยตรวจน้ำหนัก ติดตามรายสัปดาห์
−10 ถึง −20%LOWกินน้อยพิจารณาเพิ่ม 10–15% หาก น.น.ต่ำกว่าเกณฑ์
< −20%CRITICALกินน้อยมาก — เสี่ยงป่วยโทร vet, เช็คน้ำ/แสง/อุณหภูมิ, observe
ทำไมเทียบกับเกณฑ์ฟาร์ม ไม่ใช่ Ross 308

ฟาร์มไทยส่วนใหญ่ใช้ controlled-feed program ที่ให้อาหารน้อยกว่า Ross 308 ในช่วงกลางรอบ — ถ้าเทียบกับ Ross ตรงๆ ทุกเล้าจะขึ้น LIGHT/LOW ทั้งที่จริงไก่กินตามโปรแกรมฟาร์ม FarmSense จึงใช้เกณฑ์ฟาร์มเป็นหลัก แต่ยังโชว์ค่า Ross ในวงเล็บเป็นตัวเทียบรอง

8น้ำ:อาหาร — สัญญาณเตือนเบอร์ 1

แท็บ "สุขภาพ & เติบโต" · §07A

อัตราส่วน น้ำที่ดื่ม (ลิตร) : อาหารที่กิน (kg) เป็นสัญญาณเตือนสุขภาพ เร็วที่สุดในการเลี้ยงไก่ — เห็นก่อนตัวอื่นทั้งหมด

คำนวณยังไง

น้ำ:อาหาร = น้ำ (ลิตร/วัน) ÷ อาหาร (kg/วัน)
ตัวอย่าง · ฟาร์ม 10 เล้า · เล้า 1

น้ำ 13,326 ลิตร ÷ อาหาร 6,600 kg = 2.02 → OK (มาตรฐาน)

เกณฑ์ — ที่ฟาร์มไทยใช้

ratioสถานะหมายความว่า
< 0.5 หรือ > 6ข้อมูลผิดหน่วยข้อมูลผิด — ตรวจสอบไฟล์
0.5 – 1.5LOWไก่ดื่มน้ำน้อย → อาจเริ่มป่วย/หัวน้ำตัน
1.5 – 2.4OKปกติ (มาตรฐาน broiler)
> 2.4HIGHน้ำสูงผิดปกติ → heat stress / ท้องเสีย / น้ำรั่ว
สัญญาณ "ไก่กำลังจะป่วย"

ratio เปลี่ยนกะทันหันเป็นสัญญาณที่เห็นก่อนที่ไก่จะตาย — โดยทั่วไป:

📉 ratio ตกแรง (เช่น 2.0 → 1.3) = ไก่หยุดดื่มน้ำ มักจะป่วยภายใน 1–2 วัน
📈 ratio พุ่งสูง (เช่น 2.0 → 2.8) = heat stress หรือท้องเสีย เริ่มแล้ว

เห็น LOW — ทำยังไง

1. ลงเล้าเช็คหัวน้ำ — กดทดสอบ ดู cc/นาที (ดูเกณฑ์ในแท็บอุณหภูมิ § 5E)
2. เช็คแรงดันน้ำที่ปั๊ม + วาล์ว
3. ดูพฤติกรรมไก่ — กระจุกตัว? นอน? ขนแห้ง?
4. ถ้าหัวน้ำปกติแต่ไก่ไม่ดื่ม = ไก่ป่วย โทรหา vet

9น้ำหนักไก่ vs Ross 308

แท็บ "สุขภาพ & เติบโต" · §07C

เทียบน้ำหนักตัวจริง (ที่ชั่ง) กับ มาตรฐาน Ross 308 ตามอายุ — บอกว่าไก่โตเร็ว/ช้า/ตามเกณฑ์

คำนวณยังไง

มาตรฐานที่อายุนี้ = ดูจากตาราง Ross 308 (BW kg) ส่วนต่าง (%) = (น.น.จริง − มาตรฐาน) ÷ มาตรฐาน × 100
ตัวอย่าง · ฟาร์ม 10 เล้า · เล้า 1 (อายุ 36 วัน)

• น.น.จริง = 2.28 kg
• Ross 308 ที่อายุ 36 = 2.380 kg
• ส่วนต่าง = (2.28 − 2.380) ÷ 2.380 × 100 = −4.2%
→ สถานะ ON (ภายในเกณฑ์ ±5%)

เกณฑ์

ส่วนต่างสถานะการตีความ
< −5%โตช้า (BEHIND)เช็คอาหาร, สุขภาพ, density
−5% ถึง +5%ตามเกณฑ์ (ON)ปกติ
> +5%โตเร็ว (AHEAD)ดี (ถ้าทุกเล้าโตเร็ว = ระวังโตเร็วเกินอาจตายแบบ sudden death)

10อาหารหก / สูญเปล่า

แท็บ "สุขภาพ & เติบโต" · §07D

วัดช่องว่างระหว่างอาหารที่ลงเล้า กับอาหารที่ไก่กินจริง — ส่วนต่างคืออาหารที่ไม่ถึงปากไก่ (หกบนพื้น/ค้างในระบบ/ราง)

สูตร

ช่องว่าง (%) = %อาหารลงสะสม − %อาหารที่กินสะสม

เกณฑ์

ช่องว่างสถานะการตีความ
≤ 0.5%OKปกติ (อาหารส่วนใหญ่ถึงปากไก่)
0.5 – 1.0%เฝ้าระวังเริ่มมีหก — ตรวจรางและแพน
> 1.0%หกเยอะเงินรั่ว — ปรับระดับราง/ปริมาณการเดินอาหาร
เงินรั่วเท่าไหร่

ตัวอย่าง: ฟาร์ม 40,000 ตัว · ช่องว่าง 1.5% · อาหารทั้งรอบ ~160,000 kg → อาหารหก 2,400 kg × 19 บาท = ~45,600 บาทเสียเปล่าต่อรอบ (ของฟาร์มเดียวรุ่นเดียว)

11FCR & กำไรต่อตัว

แท็บ "FCR & กำไร" · §04

FCR (Feed Conversion Ratio) = อาหารที่กินหารด้วยน้ำหนักไก่ — ตัวเลขนี้กับน้ำหนักจับ ตัดสินว่ารุ่นนี้กำไรหรือขาดทุน

สูตรกำไรต่อตัว

กำไร/ตัว = (น้ำหนัก × ราคาขาย) − ราคาลูกไก่ − (น้ำหนัก × FCR × ราคาอาหาร) − ค่าจัดการ
ตัวอย่าง · สมมุติทุกอย่างมาตรฐาน

• น้ำหนักจับ 2.7 kg, FCR 1.55
• ราคาขาย 42 บาท/kg, ลูกไก่ 18, อาหาร 19, จัดการ 4

กำไร = (2.7 × 42) − 18 − (2.7 × 1.55 × 19) − 4
    = 113.4 − 18 − 79.5 − 4
    = +11.9 บาท/ตัว

Break-even FCR — จุดที่กำไรเป็นศูนย์

break-even FCR = (น้ำหนัก × ราคาขาย − ลูกไก่ − จัดการ) ÷ (น้ำหนัก × ราคาอาหาร)

ถ้า FCR จริง > break-even = ขาดทุน แม้น้ำหนักจะถึงเป้า

ตัวอย่าง

ที่น้ำหนัก 2.7 kg ราคาเดิม: break-even FCR = 1.86
ฟาร์มที่ทำ FCR ได้ < 1.86 = กำไร · > 1.86 = ขาดทุน

Sensitivity Matrix (§04A)

ตาราง 9×7 บนหน้าจอแสดงกำไร/ตัวที่ทุก FCR × ทุกน้ำหนัก — ใช้วางแผนได้ทันที ว่า "ถ้าจับ 2.8 kg ต้องคุม FCR ให้ได้เท่าไหร่"

สีในตารางกำไร/ตัวหมายความว่า
เขียวเข้ม≥ 15 บ.กำไรดี
เหลือง5 – 15กำไรพอใช้
แดงอ่อน0 – 5ใกล้ break-even
แดงทึบ< 0ขาดทุนแน่นอน
หมายเหตุ

ตารางใช้ราคาที่ตั้งไว้บนหน้าจอ (default ราคาขาย 42, ลูกไก่ 18, อาหาร 19, จัดการ 4) ปรับราคาได้ทันทีในกล่องด้านบน ตารางทุกตัวเลขจะ recompute ทันที — ใช้ลองดูสถานการณ์ราคาต่างๆ

12อุณหภูมิ & แรงลม

แท็บ "อุณหภูมิ & ลม" · §05

FarmSense ดึงเกณฑ์รายวันจากไฟล์เกณฑ์ของฟาร์มเอง (อายุ 1–42 วัน) ไม่ใช่เกณฑ์เฉลี่ยช่วงกว้าง — แม่นกว่าและเข้ากับ practice ของฟาร์มจริง

เกณฑ์สำคัญ

อายุไก่อุณหภูมิเป้าความเร็วลม FPMความหมาย
วันที่ 133°C0 (โช๊คเท่านั้น)ลูกไก่เพิ่งลง อบอุ่น ไม่ต้องลม
วันที่ 731.2°C50–150ขยายกก เริ่มเปิดลม
วันที่ 1429.1°C200–250ใช้เครื่องระบาย
วันที่ 2127°C300–400เร่งลม
วันที่ 2824.9°C500–600ลมแรงเต็มที่
วันที่ 3522.8°C600–650ก่อนจับ
วันที่ 4219.7°C600–650วันจับ
FPM ↔ m/s

1 m/s ≈ 196.85 FPM
เช่น 600 FPM ≈ 3 m/s

Wind Chill Calculator (§05C)

ใส่อายุไก่กับอุณหภูมิห้องตอนนี้ ระบบบอกว่าต้องเปิดลมแรงเท่าไหร่

ตัวอย่าง

ไก่อายุ 35 วัน · ห้อง 30°C → เกณฑ์ต้องการให้ไก่รู้สึก 22.8°C
ระบบคำนวณ: ต้องใช้ลม ≥ 2.5 m/s (≈ 492 FPM) เพื่อให้ effective temp = 22.8°C

สูตร: effective_temp = ambient − (wind_m/s × 3.4)

13ประวัติ & แนวโน้มข้ามรอบ

แท็บ "ประวัติ & แนวโน้ม" · §08

ทุกครั้งที่อัปโหลดไฟล์ ระบบจะบันทึก snapshot ไว้ในเบราว์เซอร์อัตโนมัติ — ใช้เทียบ "รุ่นนี้กับรุ่นก่อน" และดู "ตายเร่งขึ้นไหม"

ความเร็วการตาย (mortality velocity)

คำนวณระหว่าง snapshot 2 อันของฟาร์ม+รุ่นเดียวกัน:

ความเร็วการตาย = (%ตายตอนนี้ − %ตายเมื่อก่อน) ÷ (อายุตอนนี้ − อายุเมื่อก่อน)

ผลออกมาเป็น %ตายเพิ่มขึ้นต่อวัน

ตัวอย่าง

ฟาร์ม X รุ่น 14:

  • 10 พ.ค. (อายุ 30 วัน) — %ตาย = 1.5%
  • 13 พ.ค. (อายุ 33 วัน) — %ตาย = 2.4%

ความเร็ว = (2.4 − 1.5) ÷ (33 − 30) = 0.30 %/วัน → เร่งขึ้น

ความเร็วสีการตีความ
≤ 0.12 %/วันสงบปกติของช่วงเลี้ยง
0.12 – 0.25เฝ้าระวังเริ่มเร่งขึ้น ดูสาเหตุ
> 0.25เร่งขึ้นมีปัญหาเร่ง ต้องแก้ด่วน

14คำถามที่พบบ่อย

Q: ข้อมูลของฟาร์มจะถูกส่งไปไหนไหม

ไม่ — ทุกการคำนวณเกิดในเบราว์เซอร์ของคุณเท่านั้น ไม่มี server, ไม่มี cookie tracking คุณตรวจสอบได้เองโดยปิดอินเทอร์เน็ตแล้วใช้ระบบ — ใช้ได้ปกติ (ยกเว้นการโหลดฟอนต์ Google ครั้งแรก)

Q: ใช้กับไฟล์ใบหน้าเล้าของฟาร์มอื่นที่ไม่ใช่ template เดียวกันได้ไหม

ได้ — ระบบรองรับหลาย template และจะแสดงรายงานว่าหาคอลัมน์อะไรไม่เจอ ใช้ปุ่ม "⚙ ปรับการ map คอลัมน์" เลือกเองครั้งเดียว — ระบบจดจำ template นั้นไว้ ครั้งหน้าอัปโหลดไฟล์หน้าตาเดียวกันจะ map อัตโนมัติ

Q: ระบบคำนวณ %ตายสะสมเองหรืออ่านจากไฟล์

อ่านจากไฟล์ (คอลัมน์ "%ตายสะสม") — เพราะฟาร์มกรอกค่านี้ในใบหน้าเล้าอยู่แล้ว แต่ระบบมีการตรวจสอบความสอดคล้อง โดยเทียบกับ ตายสะสม÷ยอดลง×100 อัตโนมัติ

Q: คะแนนความเสี่ยงเชื่อถือได้แค่ไหน

เลขที่เห็นเลขคำนวณถูกต้อง — ผ่านการตรวจสอบอิสระ 772 จุดทุกครั้ง แต่น้ำหนักของแต่ละกฎ (เช่น "%ตาย 4% +40 คะแนน") เป็นค่าที่ตั้งตามความเหมาะสมทั่วไป — แนะนำให้สัตวบาลของฟาร์มรีวิวและปรับให้เข้ากับ practice ของฟาร์มเอง

Q: ใช้ฟรีหรือเปล่า

ฟรี — เป็นโปรเจกต์ open source บน GitHub ไม่มีค่าใช้จ่าย ไม่มีโฆษณา ไม่มีการเก็บข้อมูล

Q: ดูประวัติบนเครื่องอื่นได้ไหม

ไม่ — ประวัติเก็บในเบราว์เซอร์ของเครื่องที่อัปโหลด ถ้าจะดูบนเครื่องอื่นต้องอัปโหลดไฟล์ที่นั่นใหม่ (เป็น trade-off ของการเก็บข้อมูลใน local เพื่อความเป็นส่วนตัว)

Q: เพิ่มเกณฑ์/ปรับเกณฑ์ของฟาร์มได้ไหม

ตอนนี้ต้องแก้ใน source code (constants.js) — ในแผนการพัฒนาต่อ จะมีหน้า "ตั้งค่าเกณฑ์" ให้ปรับได้บนหน้าจอเลย
